a) **Valor exibido:** `2`

b) **Explicação:** Ocorre o fenômeno de **coerção implícita de tipo** (ou *truncamento*). Como a variável `valor_inteiro` foi declarada como `int`, ao receber um valor do tipo real (`double`/`float`), a linguagem C simplesmente descarta todas as casas decimais sem realizar arredondamento.

c) **Como evitar/controlar:** 
* Para arredondar explicitamente antes de converter, podemos usar a função `round()` da biblioteca `<math.h>` junto com casting: `valor_inteiro = (int)round(2.97);`.
* Para manter a precisão das casas decimais, a variável deve ser declarada como `float` ou `double`.
