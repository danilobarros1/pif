a) Quantidade de valores retornados e o erro em calcular():Uma função em C devolve apenas um único valor por meio do comando return.O programador pretendia devolver tanto soma quanto media simultaneamente. Porém, em return soma, media;, a vírgula funciona como o operador vírgula (comma operator): ele avalia soma, descarta esse valor, avalia media e retorna apenas o valor de media (o último operando à direita).   b) Efeito e obrigatoriedade de return; em funções void:Dentro de void imprime_mensagem(int erro), o comando return; encerra imediatamente a execução da função quando erro < 0, devolvendo o controle para quem a chamou e impedindo que a segunda mensagem (Codigo processado) seja exibida.   Ele não é obrigatório no final de uma função void, pois funções desse tipo não retornam valor; ao atingir a chave de fechamento }, a execução retorna automaticamente ao ponto de chamada.c) Funções separadas e justificativa:Cint calcular(int a, int b, int c) {
    int soma = a + b + c;
    return soma / 3;
}

int calcular_soma(int a, int b, int c) {
    return a + b + c;
}
Justificativa: Como o mecanismo de retorno padrão da linguagem C transporta apenas um dado escalar (ou uma única estrutura) de volta para o chamador via registrador/pilha, e os parâmetros são passados por valor (cópias locais), é necessário dividir a lógica em duas funções distintas quando se deseja obter dois resultados diferentes exclusivamente via return.
